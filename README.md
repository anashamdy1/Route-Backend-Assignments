# Route Backend Assignments 🚀

This repository contains all my assignments for the **Route Backend (Node.js)** track.

## 📂 Structure

Each assignment lives in its own folder:

```
Route-Backend-Assignments/
├── Assignment_1 (JavaScript)/   ✅
├── Assignment_2/                (coming soon)
└── ...
```

## ✅ Assignment 1 — JavaScript Fundamentals

- **Part 1:** 15 coding questions (`Question_1.js` → `Question_15.js`) — variables, type conversion,
  loops, continue/break, filter/map, spread & rest operators, destructuring, switch,
  arrow functions, promises, and more.
- **Part 2:** Essay questions (`Essay_Questions.js`) — forEach vs for...of, hoisting & TDZ,
  == vs ===, try-catch in async, conversion vs coercion.
- **Bonus:** Counter II (LeetCode 2665) — closures (`Bonus_Counter_II.js`).

Each file includes the original question as a comment, and can be run directly with:

```bash
node Question_1.js
```
